# Arcanes

Une application pour apprendre et pratiquer trois arts : le **tarot**, l'**astrologie** et la **magie** (astrale et hermétique).

- **Tarot** : sept jeux historiques (Marseille de Conver, Waite-Smith, Sola Busca, Grand Etteilla, Wirth…), tirages, cours, histoire, journal.
- **Astrologie** : le ciel du jour calculé sur l'appareil, vu de la Terre ou du Soleil, l'Observatoire astral, thème natal (lieux de naissance dans toutes les communes de France et les villes du monde) avec lecture guidée, lames de tarot du thème, maisons expliquées en clair, calendrier de l'année et journal des transits, école, histoire.
- **Magie** : heures planétaires, carrés d'Agrippa, atelier du sigil, Arbre de vie, géomancie, rituels guidés, cycle de 28 jours, cours en quatorze modules et quarante-deux leçons.

Tout fonctionne dans le navigateur, sans serveur ni compte : les données personnelles (journal, thèmes, carnet) restent sur l'appareil. Une sauvegarde se fait depuis Mon espace.

## Lancer en local

```
python3 -m http.server 8000
```
puis ouvrir http://localhost:8000.
